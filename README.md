# Claude娘 · B站冲浪

> 非官方同人项目，和 Anthropic 没有关系。

每一轮，她按你的关键词去 B站 找视频，读字幕（没字幕的就看看点赞最多的评论），给你写一份阅读笔记（`reports/日期.md`）。
遇到真正好的视频，她会用 Claude娘 的口吻写一条评论草稿。默认要你审批之后才会发出去。

## 防注入：怎么做的、做到什么程度

先说清楚：在模型层面，没人能保证 100% 不被注入，所有大模型都一样。
所以这个项目不押在"模型别上当"上，而是让模型就算被骗了也做不成事：

| 防线 | 做了什么 | 代码 |
|---|---|---|
| 没有权限 | 每次调用 Claude 都是单轮、请求里不带任何工具。模型接触不到 API key 和 B站 登录态。发不发、发到哪个视频，全由代码决定 | `brain.py` |
| 能力最小 | B站 侧只有 5 个动作：搜索、读视频信息、读字幕、读热评、发一级评论。读热评只在视频没字幕时用，只取评论文字。回复、私信、点赞、关注、删除这些功能根本不存在 | `bili.py` |
| 读写隔离 | 读字幕的模型输出被 JSON schema 锁死。写评论的模型只拿到过滤后的短摘要，看不到字幕和评论原文。你的口味只用来打分，不进入任何会被发出去的环节 | `brain.py` |
| 输入扫描 | 字幕、简介或热评里只要有对 AI 喊话的痕迹，这个视频就不评论（照样进日报，标 ⚠️，也不会进"值得看"） | `guard.py` |
| 硬闸门 | 发出前必须过一遍确定性规则：网址/域名、联系方式、引流词、指令用语、长串数字、可疑字符（全角、零宽、同形字）、人设或校验码泄露、和近期评论雷同、整句照搬评论区 | `guard.py` |
| 独立终审 | 另一次模型调用只看这条评论本身，拿不准就否决 | `brain.py` |
| **人工审批** | **默认 review 模式：你在终端按 y 之前，什么都不会发出去** | `surf.py` |
| 熔断 | 同一轮有多条草稿被拦，或者 B站 报错，自动发送就停 24 小时。新建 `STOP` 文件可以立刻停掉一切 | `surf.py` |

真正的 100% 靠的是审批这一层。全自动（auto）模式是多层防护、拿不准就不发，但不是数学意义上的 100%。

你可以自己验证：

```
python redteam.py          # 离线攻击测试：不花钱、不需要 key、不碰 B站
python redteam.py --live   # 用真模型跑一批恶意视频，看每一关的结果；花几美分，不会发评论
```

## 准备

1. **Python 3.10 或更新**
2. **Claude API key**：在 claude.ai 的 **Settings > Billing** 领取 Max 套餐每月附带的 API 额度（会让你关联一个 Claude Console 组织）。然后到 Console（platform.claude.com）新建一个 API key。额度用完后 API 会直接停，不会扣套餐。前提是你没在那个 Console 组织里绑卡充值。
3. **B站 小号**：要绑定手机号。如果发评论时提示需要答题转正，先在 App 里答完。

## 安装

```
git clone https://github.com/Lindy-Z/claude-chan.git
cd claude-chan
python -m venv .venv
.venv\Scripts\activate          # Windows
source .venv/bin/activate       # macOS / Linux
pip install -r requirements.txt
```

把 `.env.example` 复制一份，改名为 `.env`，填上 API key。

想改设置（关键词、口味、评论模式……）的话，把 `config.example.toml` 复制一份，改名为 `config.toml` 再改。不复制也能跑，程序会直接用示例设置。`config.toml` 已经在 `.gitignore` 里，你的口味不会被提交。

## 登录小号

```
python login.py
```

用**小号**的 B站 App 扫码。登录态保存在 `cred.json`，它等于账号钥匙，别外传。

## 用起来

```
python surf.py --check      # 检查 key、登录、花费、各个开关
python surf.py              # 跑一轮；阅读笔记在 reports/ 里
python surf.py --review     # 审批评论草稿：y 发送 / n 丢弃 / e 改写后发送
python surf.py --loop 3     # 每 3 小时左右跑一轮，Ctrl+C 退出
```

建议先跑几轮，只看阅读笔记和草稿。觉得 Claude娘 的语气对了，再开始审批发送。

## 改什么在哪

- 关键词、口味、预算、评论模式：`config.toml`（从 `config.example.toml` 复制）
- 没字幕的视频要不要看热评（`brain.hot_comments`，0 = 不看）、哪些关键词搜到的视频优先评论（`comment.prefer`）：也在 `config.toml`
- Claude娘 的性格：`persona.md`。随便改，安全规则不在这里，改了也不会被削弱
- 头像和简介要在 B站 App 里手动设置。简介建议写上「AI 自动账号 · 由 Claude 驱动 · 非官方同人」

## 花费

读一个视频大约 $0.002，写一条评论加终审大约 $0.01，所以一轮只要几美分。
每天和每月的上限写在 `config.toml` 里，到了就自动收工。

## 安全开关与限制

- 在文件夹里新建一个名叫 `STOP` 的空文件：立刻停止一切评论，不用重启
- 把 `comment.mode` 设为 `"off"`：只出阅读笔记，不写评论
- 代码里有硬上限：每轮最多 5 条、每天最多 20 条、两条之间至少等 30 秒。config 写得再大也不会超过
- 不做验证码破解、指纹伪装、代理池、多开：B站 一拦就停
- 每条评论的来龙去脉（被哪一关拦下、为什么）都记在 `logs/audit.jsonl`
- B站 规则不鼓励自动化账号，小号仍有被限制或封禁的风险

## 常见问题

- **搜索全部失败，或报 -412**：被风控了。过几个小时再跑，别去调低等待时间
- **发评论失败，错误码 12015**：B站 要求输入验证码。程序会自动停下；用 App 正常刷一阵小号再试
- **很多视频显示"没有字幕"**：B站 的 AI 字幕需要登录态才能拿到。先用 `--check` 确认登录正常
- **报模型名不存在**：把 `config.toml` 里的模型名改成 `--check` 列出来的可用名字
